# Synthés historiques : signatures et traduction

Quand une source dit « fait sur un X », cette table donne le caractère à viser et la machine cible.
**M** = Moog Messenger (mono, analogique, sans effets) · **XD** = Korg minilogue XD (4 voix, effets).

| Synthé d'origine | Signature sonore | Cible | Stratégie de traduction |
|---|---|---|---|
| **Minimoog Model D** | 3 VCO, ladder 24 dB, glide expo, mixer qui sature | **M** | natif ; FB/EXT IN pour la saturation du mixer ; OSC 2 en quinte ou désaccordé |
| **Moog modulaire** (Emerson, Wendy Carlos, Moroder) | carrés / scies épais, glide, séquences | **M** | sons simples, souvent 2 osc ; séquenceur pour Moroder |
| **Moog Taurus** | basse pédale énorme | **M** | 2 osc scie désaccordés à 16'/32', sub, filtre bas, decay long |
| **Roland TB-303** | 1 osc scie/carré, filtre ~18 dB résonant, accent, slide | **M** | 4P LP, RES BASS off, F ENV VEL, legato glide temps constant |
| **Roland SH-101** | 1 osc + sub, pulse/scie mélangés, filtre IR3109 | **M** | WAVESHAPE + SUB, résonance modérée |
| **Roland Juno-60 / 106** | 1 DCO + sub, PWM, chorus Juno indispensable | **XD** | pulse + LFO → SHAPE, MOD FX chorus ; poly |
| **Roland Jupiter-8** | 2 VCO, sync, cross-mod, lisse, épais | **XD** (poly) / **M** (lead) | detune, sync, unison XD |
| **Sequential Prophet-5** | poly-mod, filtre punchy, brass 80s | **XD** | 2 osc désaccordés, env. filtre, cross mod |
| **Oberheim OB-X / OB-Xa / SEM** | filtre 12 dB ouvert, brass « Jump » énorme | **XD** | scies désaccordées, filtre assez ouvert, chorus ; unison pour l'épaisseur |
| **Yamaha CS-80** | Blade Runner, cuivres expressifs, aftertouch | **XD** | attaque moyenne, filtre + aftertouch, reverb longue |
| **ARP Odyssey / 2600** | duophonique, filtre agressif, sync | **M** | sync 1→2, résonance |
| **Korg MS-20** | filtre HP + LP qui crie, sale | **XD** / **M** | XD : drive filtre ; M : 2P LP, résonance, FB |
| **Yamaha DX7** | FM : E-piano, basse « slap », cloches | **XD** (VPM du multi-engine) | approximation ; M : 1→2 FM limité |
| **Access Virus / supersaw** (trance) | 7 scies désaccordées, stéréo | **XD** | VOICE MODE UNISON + chorus ; M : approximation |
| **Roland TR-808 / 909** (kick, perc) | sinus avec enveloppe de hauteur | **M** | résonance en auto-oscillation + env. sur cutoff/OSC ; ou XD bruit |

## Choisir la machine

1. Le son est **joué en accords / nappe** → XD (le Messenger est monophonique).
2. Le son dépend **d'un effet** (chorus Juno, delay, reverb) → XD.
3. **Basse, lead mono, acid, glide, gros analogique Moog** → Messenger.
4. En cas d'égalité, préférer le **Messenger** pour les mono (filtre ladder) et le noter.
