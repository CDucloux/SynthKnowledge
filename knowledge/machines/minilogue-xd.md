# Korg minilogue XD — en attente du manuel

> **Statut : template NON créé.** Le manuel n'est pas encore dans `manuels/`.
> Ce qui suit vient des connaissances générales de Claude et **doit être vérifié** contre le manuel avant de construire `template/minilogue-xd.typ` (voir skill `ajouter-synthe`).

## Vue d'ensemble (à vérifier)

- Polyphonique **4 voix**, analogique (2 VCO + filtre) + **multi-engine numérique** (bruit, VPM/FM, oscillateurs utilisateur).
- **Effets** : MOD FX (chorus, ensemble, phaser, flanger, user), DELAY, REVERB.
- Filtre passe-bas **2 pôles** avec DRIVE et KEY TRACK (positions 0 / 50 / 100 %).
- VOICE MODE : POLY / UNISON / CHORD / ARP-LATCH, avec VOICE MODE DEPTH.
- Valeurs affichées à l'écran (souvent 0-1023) → **la fiche XD utilisera les valeurs écran** plutôt que des heures d'horloge.

## Quand choisir le XD plutôt que le Messenger

Accords / nappes, sons qui dépendent d'un chorus, d'un delay ou d'une reverb, FM type DX (VPM), unison épais.
