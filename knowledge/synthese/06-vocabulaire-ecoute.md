# De l'adjectif au paramètre

Table de traduction utilisée pour (1) interpréter les descriptions de l'utilisateur et des sources,
(2) rédiger l'encadré **« Ajuster à l'oreille »** des fiches.

| On entend / on dit… | Paramètres probables |
|---|---|
| brillant, tranchant, criard | cutoff haut, scie ou pulse étroit, résonance |
| sombre, étouffé, feutré | cutoff bas, triangle/sinus, peu d'env. filtre |
| creux, boisé, clarinette | carré, impairs ; passe-bas modéré |
| nasal, « canard », hautbois | pulse étroit, passe-bande, résonance moyenne |
| gras, épais, « fat » | 2 osc désaccordés, sub, saturation, passe-bas 24 dB |
| fin, maigre | un seul osc, passe-haut, peu de grave (RES BASS off + résonance) |
| percussif, pluck, « pok » | attaque 0, decay de filtre court, sustain 0 |
| mou, lent à parler | attaque d'ampli ou de filtre > 30 ms |
| liquide, squelchy, acid | résonance haute + env. filtre courte + glide |
| « wah », qui parle, vocal | résonance + modulation du cutoff (env, LFO, aftertouch) ; passe-bande |
| wobble | LFO synchro → cutoff |
| qui ondule, chorusé | detune, PWM, chorus |
| qui vibre (hauteur) | vibrato LFO → pitch |
| qui pulse (volume) | trémolo LFO → amp, ou env. ampli en boucle |
| métallique, cloche | FM / cross mod, ring mod, wavefold ; rapports non entiers |
| glissant, qui « chante » | glide / portamento |
| qui sature, grogne, « growl » | feedback / drive, OSC 2 → cutoff, wavefold |
| soufflé, aérien | bruit dans le mixer, passe-haut, attaque lente |
| « 8-bit », chiptune | carré ou pulse sans filtre, enveloppes sèches, arpège rapide |

## Questions de diagnostic (dans cet ordre)

1. **Hauteur / registre** : basse, médium, aigu ? → OCTAVE.
2. **Monophonique ou accords** ? → choix de la machine (Messenger mono, XD 4 voix).
3. **Forme de base** : creux / plein / nasal / pur ? → forme d'onde.
4. **Brillance et son évolution** : statique ? s'ouvre ? se ferme ? → cutoff + env. filtre.
5. **Articulation** : attaque, durée, queue → env. ampli.
6. **Mouvement** : vibrato, wah, pulsation → LFO.
7. **Glissés** → glide.
8. **Espace / effets** → FX (ou alternative).
